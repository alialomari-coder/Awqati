# تقديم أوقاتي 8.2.2 إلى متجر NVDA يدويًا

تاريخ التحقق: 21 نوفمبر 2026. لم يُرسل النموذج ولم يُنشأ طلب تحديث آليًا.

## القيم بالترتيب

1. Title: `[Submit add-on]: Awqati 8.2.2`
2. Download URL: `https://github.com/alialomari-coder/Awqati/releases/download/v8.2.2/awqati-8.2.2.nvda-addon`
3. Source URL: `https://github.com/alialomari-coder/Awqati/tree/v8.2.2`
4. Publisher: `ali alomari`
5. Channel: `stable`
6. License Name: `GPL v2 or later`
7. License URL: `https://www.gnu.org/licenses/old-licenses/gpl-2.0.html`

## التقديم باستخدام Chrome وNVDA

1. سجل الدخول إلى GitHub بحساب alialomari-coder. افتح Chrome واضغط Control+L، والصق رابط النموذج ثم Enter:
   https://github.com/nvaccess/addon-datastore/issues/new?template=registerAddon.yml
2. استخدم NVDA+Space للوصول إلى نمط التصفح إن لزم. اضغط E للتنقل إلى حقول التحرير، واستمع لاسم الحقل. ابدأ بحقل Title أو Add a title، ثم أدخل القيم أعلاه حسب أسمائها. اضغط Enter على الحقل للدخول في نمط التركيز عند الحاجة. استخدم Control+A لاستبدال القيم الافتراضية في حقلي الترخيص.
3. انتقل بـTab إلى Channel. افتح القائمة بـAlt+السهم لأسفل أو Space حسب نوع العنصر، واختر stable بالأسهم ثم Enter. إذا كانت القائمة مخصصة، استخدم Tab للوصول إلى stable ثم Enter.
4. راجع الحقول بـShift+Tab وTab واستمع إلى القيم؛ انتبه إلى الإصدار 8.2.2 في رابطَي التنزيل والمصدر.
5. عند استعدادك، انتقل بـTab إلى Create أو Submit new issue ثم Enter لإرسال الطلب مرة واحدة بنفسك. إن ظهر خيار مراجعة قبل الإرسال، راجع البيانات ثم تابع يدويًا. احفظ رابط الطلب وطلب الدمج الناتج. الإرسال وحده لا يعني القبول.

لا يوجد حقل مستقل للبصمة أو رقم الإصدار أو التوافق أو المستجدات؛ تُقرأ بيانات الإضافة من الحزمة. لا حاجة إلى لصق وصف إصدار إضافي.
