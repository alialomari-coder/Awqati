# Awqati 8.2.2

Version 8.2.2

- Restores Arabic Wikipedia events, including November 21, while preserving the original text and article links.
- Allows another attempt for an unreadable Wikipedia section when requested after at least 15 minutes. The wait survives a restart, respects the source's request limits and preserves readable sections.
- Updates the add-on summary and description to include weather and date converters, and provides Arabic release notes.

Earlier release history is available in the add-on help.
