# Awqati 8.2.1

Awqati 8.2.1 is the current stable release of the NVDA add-on for prayer times, clocks, calendars, astronomy, weather, and daily time management. It supports Arabic and English.

This release follows the previously published 4.0.0 release. Intermediate development versions are recorded in the change history; they are not being published retroactively.

## Highlights since 4.0.0

- Four time management tools: personal alarms, countdown timers, a stopwatch, and a world clock, with keyboard commands and status announcements.
- On This Day information from Wikipedia: events, births, deaths, holidays, and observances in Arabic and English, with direct reading, accessible web pages, original article links, and daily caching.
- Basic and advanced historical date converters for Hijri, Gregorian, and Julian dates, including historical arithmetic IIc and Umm al-Qura where supported, with a shared result window.
- An expanded daily astronomical synopsis: solar transit and altitude, seasonal daylight changes, Earth–Sun distance, lunar rise and set, lunar meridian transit and independent maximum altitude, Earth–Moon distance, and upcoming principal phases. The traditional Arabian calendar remains a separate section.
- Optional Open-Meteo weather: current conditions, daily and hourly forecasts, configurable units and detail, accessible text reports, and an optional daily synopsis summary. Weather is disabled by default and requires an Internet connection when enabled.
- Bilingual report and documentation refinements, clearer accessible naming in text-report dialogs, and focus restoration when dialogs close. Existing settings are preserved through the documented migrations.

These extend the existing prayer times and alerts, Zawali and Ghurubi clocks, five calendars, Qibla information, daily Wird and adhkar reminders, and quiet-hours controls.

## Changes in 8.2.1

- Shorter sentences in detailed Arabic current-weather narration, preserving values, ordering, units, and selected information.
- Natural dry-period wording when the available forecast crosses midnight.
- More precise maximum hourly rain-probability wording, explicitly referring to the available hours of the day.

The change history records 18 focused automated checks and 26 checks in isolated NVDA 2026.1 sessions for this correction. Earlier weather-release checks also covered NVDA 2026.3.1. These are historical results, not new test runs performed during publication; automated probes do not constitute human listening tests.

## Requirements, installation, and upgrade

- Windows with **NVDA 2026.1 or later**. The package declares **NVDA 2026.3.1** as its last tested version.
- Interface and full user guides in **Arabic and English**.
- No separate Python installation is required to use the add-on.

Download **awqati-8.2.1.nvda-addon** below, open it while NVDA is running, and follow the installation and restart prompts. Alternatively, use **Install from external source** in NVDA's Add-on Store. Install over the existing Awqati add-on to upgrade, then restart NVDA. Existing settings are retained. Choose a location on first use, or later in Awqati settings.
