# Awqati 8.2.3

الإصدار الرسمي المستقر 8.2.3

- تنظيم قائمة أوقاتي ضمن قائمة أدوات NVDA للوصول المباشر إلى الخدمات.
- استقلال أدوات الساعة الأربع: المنبهات الشخصية، والمؤقتات، وساعة الإيقاف، والساعة العالمية.
- تحسين المنبهات الشخصية ودعم المنبه لمرة واحدة وحفظ أيام التكرار.
- الوصول إلى تقارير الطقس النصية القابلة للتصفح والنسخ من القائمة.
- الوصول إلى صفحات «حدث في مثل هذا اليوم» من القائمة.
- المحافظة على الاختصارات والإعدادات والبيانات السابقة.

Stable release 8.2.3

- Organizes Awqati services under the NVDA Tools menu.
- Keeps four independent clock tools: personal alarms, countdown timers, stopwatch and world clock.
- Improves personal alarms, including one-time alarms and saved repeat days.
- Provides menu access to browsable, copyable weather text reports.
- Provides menu access to On This Day web pages.
- Preserves existing shortcuts, settings and stored data.

NVDA compatibility: 2026.1.0 through last tested version 2026.3.1.
