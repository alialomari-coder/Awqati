# دليل اختصار الطقس السريع — أوقاتي 8.0.2

- NVDA+W: بالضغط عليه مرة واحدة يعلن عن حالة الطقس الحالية، وبالضغط عليه مرتين يعلن عن توقعات الطقس لليوم، وبالضغط عليه ثلاث مرات يعلن عن توقعات الطقس للأيام القادمة.
- فتح معلومات الطقس في نافذة نصية: أمر قابل للتخصيص بلا اختصار افتراضي.

# Weather quick shortcut guide

- NVDA+W: Press once to announce the current weather, twice to announce today's weather forecast, or three times to announce the weather forecast for the coming days.
- Open weather information in a text window: assignable, no default gesture.

- NVDA+Alt+W: فتح إعدادات الطقس مباشرة؛ Open weather settings directly.

النافذة تحفظ آخر تقرير ناجح دون اتصال جديد؛ The window preserves the last successful report without a new connection.
